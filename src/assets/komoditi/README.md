# Commodity Images

This folder contains real images for Indonesian food commodities used in the SATRIA HARGA system.

## Required Images (PNG format, ~100-200px, transparent background recommended):

1. **bawang-merah.png** - Shallots/Red onion (Bawang Merah)
2. **bawang-putih.png** - Garlic (Bawang Putih)
3. **cabai-merah.png** - Red chili pepper (Cabai Merah)
4. **cabai-rawit.png** - Bird's eye chili (Cabai Rawit)
5. **daging-ayam.png** - Chicken meat (Daging Ayam)
6. **daging-sapi.png** - Beef (Daging Sapi)
7. **minyak-goreng.png** - Cooking oil bottle (Minyak Goreng)
8. **telur-ayam.png** - Chicken eggs (Telur Ayam)
9. **tomat.png** - Tomato (Tomat)
